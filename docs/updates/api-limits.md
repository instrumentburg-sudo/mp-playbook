# API: лимиты и возможности WB / Ozon / MPStats

Сводка на 23.04.2026. Конвейер новинок опирается на три источника: **MPStats API** (рыночная аналитика до запуска), **WB Content / Statistics API** и **Ozon Seller API** (свои данные после запуска).

## 1. Сравнительная таблица

| | MPStats API | Wildberries API | Ozon Seller API |
|---|---|---|---|
| Чьи данные | Рынок целиком (конкуренты, ниши) | Только свой личный кабинет | Только свой личный кабинет |
| Цена | от ~7 000 ₽/мес (Advanced / Premium) | Бесплатно | Бесплатно |
| Нужен личный кабинет продавца | Нет | **Да** (API-ключ из WB Seller) | **Да** (Client ID + Api Key) |
| Общий лимит запросов | ~100 запросов/мин | 3 запроса / 30 сек на метод | 30 000 операций/мин |
| Где нужен в конвейере | **Фазы 1–2:** идея, анализ ниши | **Фазы 6–8:** запуск и масштабирование | **Фазы 6–8:** запуск и масштабирование |

## 2. MPStats API

**Документация:** [mpstats.io/api](https://mpstats.io/api), [docs.mpstats.io](https://docs.mpstats.io).

Ключевые точки доступа для конвейера:

- **Category** — анализ категории: топ-продавцов, распределение выручки, новые карточки.
- **Keywords** — частотность запросов, сезонность, связанные ключи.
- **SKU** — детальные показатели карточки (выручка, остатки, упущенная выручка).
- **Search** — поиск по фото, названию, артикулу.
- **Trends** — динамика ниши по месяцам.

**Тариф с API:** Advanced Jam / Premium Jam — обычно 7 000–15 000 ₽/мес. Уточнять у менеджера, потому что тарифный конструктор меняется.

**Как использовать в стартовой версии конвейера:**
1. `calc-niche-potential.py` — принимает категорию + бюджет → возвращает топ-20 артикулов по выручке с возрастом меньше 90 дней и отзывами меньше 50.
2. `fetch-seo-semantics.py` — по артикулам конкурентов собирает поисковые запросы (с отсечением низкочастотных меньше 1000 и латиницы).

## 3. Wildberries API

**Адреса:**
- `suppliers-api.wildberries.ru` — общая точка входа.
- `openapi.wildberries.ru` — документация Swagger.
- `dev.wildberries.ru` — заметки о выпусках и часто задаваемые вопросы.

**Основные разделы:**

| Раздел | Для чего | Лимит |
|---|---|---|
| `/content` | Карточки товаров: создание, обновление, медиа | 3 запроса / 30 сек |
| `/statistics` | Свои продажи, заказы, остатки, возвраты | 3 запроса / 30 сек |
| `/analytics` | Расширенная аналитика, детализация продаж | 1 запрос/мин, 30 строк (100 на тарифе Advanced) |
| `/promotion` | Рекламные кампании: создание, ставки, отчёты | 3 запроса / 30 сек |
| `/reports` | Финансовые отчёты, акты, детализация выплат | 1 запрос/мин |
| `/warehouses` (новый, 23.03.26) | Инвентаризация склада | 1 запрос / 20 сек, 250 000 строк |

**API-ключ:** кабинет WB Seller → «Настройки» → «Доступ к API» → «Сгенерировать токен». Токен привязан к JWT, срок 180 дней (в 2026 планируют продление).

**Разделы доступа:** Content, Statistics, Analytics, Promotion, Recommendations, Feedbacks, Marketplace, Buyer, Return, Calendar. Каждому — отдельный признак.

**Частые сценарии:**
- Выгрузка продаж за период: `/api/v1/supplier/sales?dateFrom=...` (1 запрос/мин).
- Обновление остатков для отгрузки со своего склада: `/api/v3/stocks/{warehouseId}` (3 запроса / 30 сек).
- Массовое создание карточек: `/content/v2/cards/upload` — порциями по 3 000 карточек, идентификатор задачи `taskId` для проверки статуса.

## 4. Ozon Seller API

**Адрес:** `api-seller.ozon.ru`.
**Документация:** [docs.ozon.ru/api/seller](https://docs.ozon.ru/api/seller/).

**Авторизация:** два заголовка — `Client-Id` и `Api-Key`. Получить: кабинет Ozon Seller → «Настройки» → «API».

**Общий лимит** (с 24.02.2026): **30 000 операций с товарами в минуту**. При превышении — ответ `429 Too Many Requests` с заголовками `Retry-After: <сек>` и `Remaining: <элементов>`.

**Важно:** если в одном запросе превышено число товаров — весь запрос отклоняется, ни одно обновление не проходит. Пример: `limit=1000`, а осталось `500` → `429`, и всё. Бить на партии вручную.

**Основные точки доступа** (актуально на апрель 2026):

| Путь | Для чего |
|---|---|
| `/v3/product/list` | Список товаров (с фильтрами) |
| `/v3/product/info/list` | Детали по списку product_id |
| `/v1/product/pictures/import` | Загрузка изображений |
| `/v3/posting/fbs/list` | Заказы для отгрузки со своего склада (с 06.04.26 добавлен `Tarification_steps`) |
| `/v2/posting/fbo/list` | Заказы для отгрузки со склада площадки |
| `/v1/analytics/data` | Аналитика: показы, клики, заказы, выручка |
| `/v1/finance/transaction/list/v3` | Финансовые операции |
| `/v1/finance/realization` | Отчёт о реализации |
| `/v1/review/list` | Отзывы |

**С 07.04.2026** устарели старые методы для отгрузки со своего склада (FBS / rFBS) для работы с заказами и остатками — проверять переход на v3.

**Performance API** (для продавцов из РФ, с 06.04.2026) получил авторизацию OAuth. Нужен для управления рекламой:
- `/api/client/campaign` — кампании («Трафареты», «Продвижение в поиске», баннеры).
- `/api/client/statistics` — отчёты по кампаниям.

## 5. Связка: как данные текут через конвейер

```
 Фаза 1 ИДЕЯ        ─┐
 Фаза 2 РЫНОК       ─┼─► MPStats API (чужой рынок)
 Фаза 3 ПОСТАВЩИК   ─┘       │
                            ▼
                      Контрольная точка ЮНИТ-ЭКОНОМИКА
                            │
                            ▼
 Фаза 4 ЮНИТ-ЭКОНОМИКА ◄─ локальный расчёт (commissions/*.yaml + свои формулы)
 Фаза 5 ЗАКУПКА    ◄─ вручную (1688, логистика, таможня)
                            │
                            ▼
 Фаза 6 КАРТОЧКА   ◄─ WB Content API / Ozon Product API (загрузка карточек)
 Фаза 7 ЗАПУСК    ◄─ WB Statistics + Promotion / Ozon Analytics + Performance
 Фаза 8 МАСШТАБ    ◄─ всё то же, ежедневная выгрузка в sales-log.csv
```

## 6. Чего **нет** в API

- **1688.com:** публичного стабильного API нет. Работа через интерфейс + поиск по фото либо посредник или сбор данных через браузер. AliBaba International имеет API, но ассортимент и цены хуже.
- **«Честный знак»** (маркировка): отдельный API, нужен только для маркируемых категорий (одежда, обувь, парфюм и т. д.).
- **Таможня (ФТС):** оформление таможенной декларации через брокера, не через API.
- **Сертификация ЕАЭС:** реестр Росаккредитации читается, но процесс заявки — через аккредитованную лабораторию.
