## 3. API и лимиты

### Wildberries
- Общий rate limit: **3 req / 30 sec** на метод на хост.
- Analytics API: **1 req/min**, 30 строк (100 на Advanced/Premium Jam), до 100 000 строк в одном ответе.
- Warehouse inventory (с 23.03.2026): **1 req/20 sec**, 250 000 строк.
- Разделы: `/content`, `/statistics`, `/analytics`, `/promotion` (РК), `/reports` (финансовые отчёты).
- Документация: `dev.wildberries.ru`, `openapi.wildberries.ru`.

### Ozon Seller API
- С 24.02.2026 единый лимит: **30 000 операций с товарами в минуту**. Превышение → `429` с `Retry-After` и `Remaining` items.
- С 06.04.2026: новый блок `Tarification_steps` в `/v3/posting/fbs/list`; в Performance API РФ-продавцов внедрили OAuth (было только в Seller API).
- С 07.04.2026 устаревшие методы FBS/rFBS — deprecated.
- Документация: `docs.ozon.ru/api/seller/`, `dev.ozon.ru/news/`.

### 1688 / Alibaba
- Публичного стабильного API для 1688 нет; используется поиск по фото + фильтры в UI, либо посредник/браузерная автоматизация.
- Для Alibaba — официальный RapidAPI, но ассортимент и цены хуже чем на 1688.

## 4. Импорт из Китая — актуальная модель

**Выбор поставщика на 1688** (из курса + современные правки):
1. Поиск по фото, сортировка по обороту (выручке).
2. Иконки на фабрике: «красный бык» / «фиолетовый бриллиант» = проверено.
3. Возраст фабрики ≥ 3 лет, % повторных покупок ≥ 20–35%.
4. Запросить реальные фото/видео (без иероглифов на упаковке — только EN/RU).
5. Тестовая мини-партия до основного заказа.
6. На коробках — штрихкоды и маркировка под ЕАЭС.

**Логистика**:
- Карго авто: 18–25 дн (экономично, но риск при усилении СПОТ).
- Карго быстрое авто: 12–16 дн.
- Авиа: 8–12 дн (дорого).

**Белый vs серый импорт** (2026):
- Серый (карго без ДТ) → блокировка сертификатов, штрафы, нельзя в B2B/тендеры/ЕАЭС.
- Белый → ДТ, сертификат/декларация с реальными испытаниями, вычет НДС (если на НДС), участие в тендерах, легальный экспорт.
- Для ИП с оборотом >20 млн ₽ белый путь становится единственным разумным.

## 5. Юнит-экономика — правки 2026

Курс даёт примеры с **WB комиссией 20%** и **Ozon 12%**. На апрель 2026 это нижняя граница; нужно пересчитывать по актуальной таблице комиссий с учётом:

- **WB комиссия FBO** по категориям: 10–25% (комиссия стабильна, но логистика FBS выросла).
- **Ozon комиссия FBO** с 06.04.2026: 15–55%. Ценовой сегмент влияет (до 100 ₽, 100.01–300, 300.01–1500, 1500.01–5000, 5000.01–10 000, >10 000).
- **Логистика Ozon** снизилась в 3–4 раза для товаров ≥5 л, но в сумме большинство селлеров в минусе.
- **Налог**: УСН 6% (либо УСН+НДС 5% без вычетов с >20 млн выручки, либо УСН+НДС 7% с вычетами).

Рабочая формула на 2026:

```
Profit = Price - (COGS + Fulfillment + MP_Commission + Logistics_client + Refunds_logistics
                  + Defect_rate × Price + Ad_spend + Tax_on_revenue)

ROI_year = (Profit_per_batch / Invested_capital) × Cycles_per_year
```

«Зелёная зона» (ориентиры после правок):
- Маржа WB: 15–25% (курс актуален).
- Маржа Ozon: **12–18%** (снизили vs курс 16–22% из-за роста комиссий).
- ДРР WB: 5–10%.
- ДРР Ozon: **15–25%** (увеличиваем резерв).
- Оборот капитала: 2–3 мес (51–104 дня).
- ROI годовой: >150% считать базой, 200–400% — цель.

## 6. Правила запуска без блокировки

Что из курса **ещё работает** в 2026:
- Развозка по 5–6 региональным складам (для WB — критично для топа).
- Кросс-докинг на Ozon ~500 ₽/короб.
- Сбор семантики через топ-20–30 конкурентов по выручке, чистка латиницы/НЧ <1000.
- «Сухое» SEO на Ozon + лишний текст в Rich-контент.
- Аукцион + АвтоРК на WB (при этом исключать ключи из АвтоРК, чтобы не каннибализировать Аукцион).
- На Ozon стартовать с Трафаретов (автостратегия), потом Вывод в топ — только после стабильной конверсии.

Что **не работает** / **опасно** в 2026:
- ❌ Самовыкупы (и на WB, и на Ozon).
- ❌ Болванки «чехол→фен» (запрещено в обеих площадках).
- ❌ Кэшбэк-раздачи с обещанием вознаграждения за отзыв вне «Баллов за отзывы».
- ❌ Дублирование «Баллы за отзывы» (Ozon) + сторонние раздачи — двойная оплата.
- ⚠️ Дробление бизнеса на ИП родственников: запрещены общий IP, склад, сотрудники, внутренние переводы. При обороте >30 млн в «льготном» регионе — обязательное подтверждение присутствия (KZK, Калмыкия, Удмуртия и т.п.) + правило 3 лет.

Что **появилось** и надо учесть:
- ✅ «Баллы за отзывы» — единственный легальный драйвер отзывов на WB. Мин. 21 день, предоплата, старт со след. дня.
- ✅ «Отзывы за баллы» Ozon — встроенный, дешевле сторонних, без риска двойной оплаты.
- ✅ Промокоды продавца на WB (инструмент 2026), собственные акции против массовых общих.
- ✅ Нейросеть отзывов WB (2026) — модерация жёстче, фейковые/копипаст режутся.
- ✅ Сертификат обязателен + ссылка на реестр с сентября 2026 — закладывать в пайплайн.

## 7. Инфографика 2026 — конкретные инсайты

- 2–4 секунды на просмотр карточки: одна идея на один слайд, первый слайд — главное УТП, без текстовой вёрстки преимуществ.
- 3-й слайд **влияет на CTR и открытие** (данные vc.ru: реорганизация карусели → +34% конверсии).
- Текст-преимущества на первых 3 слайдах → ХУЖЕ конверсия, чем упор на визуал.
- Качественная инфографика → CTR +25–40% (данные WB/Ozon).
- На Ozon можно дублировать контент с WB (размеры совместимы), но следить за «индексом цен» — Ozon сравнивает.

## 8. Юридическая гигиена на 2026 (для ИП)

1. **НДС**: при доходе >20 млн ₽/год — либо НДС 5% без вычетов (проще, подходит при малой доле закупа), либо НДС 7% с вычетами (выгоднее при белом импорте и большой доле чужого НДС во входящих).
2. **Льготный регион**: при переезде — правило 3 лет, дорогая подготовка доказательной базы (собственность, местный сотрудник после 30 млн, местные коммуналки/СИМ, членство в Опоре России, пожертвования). Окупается только на оборотах >10–15 млн/год.
3. **Сертификация**: закладывать в юнит-экономику 20–100 тыс ₽ на SKU за декларацию/сертификат, 2–6 недель времени.
4. **Штрихкоды и маркировка** (Честный знак): обязательно для одежды, обуви, парфюма, фототехники, БАД и т.д. Проверить ДО закупки.
5. **Таможня**: ДТ при ≥200 евро/≥31 кг на посылку; оформление через брокера, 3–10 тыс ₽/ДТ.
