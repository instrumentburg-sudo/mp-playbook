## 3. API и лимиты

### Wildberries
- Общий rate limit: **3 req / 30 sec** на метод на хост.
- Analytics API: **1 req/min**, 30 строк (100 на Advanced/Premium Jam), до 100 000 строк в одном ответе.
- Warehouse inventory (с 23.03.2026): **1 req/20 sec**, 250 000 строк.
- Разделы: `/content`, `/statistics`, `/analytics`, `/promotion` (РК), `/reports` (финансовые отчёты).
- Документация: `dev.wildberries.ru`, `openapi.wildberries.ru`.

### Ozon Seller API
- С 24.02.2026 единый лимит: **30 000 операций с товарами в минуту**. Превышение → `429` с `Retry-After` и `Remaining` items.
- С 06.04.2026: новый блок `Tarification_steps` в `/v3/posting/fbs/list`; в Performance API РФ-продавцов внедрили OAuth (было только в Seller API).
- С 07.04.2026 устаревшие методы FBS/rFBS — deprecated.
- Документация: `docs.ozon.ru/api/seller/`, `dev.ozon.ru/news/`.

### 1688 / Alibaba
- Публичного стабильного API для 1688 нет; используется поиск по фото + фильтры в UI, либо посредник/браузерная автоматизация.
- Для Alibaba — официальный RapidAPI, но ассортимент и цены хуже чем на 1688.

## 4. Импорт из Китая — актуальная модель

**Выбор поставщика на 1688** (из курса + современные правки):
1. Поиск по фото, сортировка по обороту (выручке).
2. Иконки на фабрике: «красный бык» / «фиолетовый бриллиант» = проверено.
3. Возраст фабрики ≥ 3 лет, % повторных покупок ≥ 20–35%.
4. Запросить реальные фото/видео (без иероглифов на упаковке — только EN/RU).
5. Тестовая мини-партия до основного заказа.
6. На коробках — штрихкоды и маркировка под ЕАЭС.

**Логистика**:
- Карго авто: 18–25 дн (экономично, но риск при усилении СПОТ).
- Карго быстрое авто: 12–16 дн.
- Авиа: 8–12 дн (дорого).

**Белый vs серый импорт** (2026):
- Серый (карго без ДТ) → блокировка сертификатов, штрафы, нельзя в B2B/тендеры/ЕАЭС.
- Белый → ДТ, сертификат/декларация с реальными испытаниями, вычет НДС (если на НДС), участие в тендерах, легальный экспорт.
- Для ИП с оборотом >20 млн ₽ белый путь становится единственным разумным.

## 5. Юнит-экономика — правки 2026

Курс даёт примеры с **WB комиссией 20%** и **Ozon 12%**. На апрель 2026 это нижняя граница; нужно пересчитывать по актуальной таблице комиссий с учётом:

- **WB комиссия FBO** по категориям: 10–25% (комиссия стабильна, но логистика FBS выросла).
- **Ozon комиссия FBO** с 06.04.2026: 15–55%. Ценовой сегмент влияет (до 100 ₽, 100.01–300, 300.01–1500, 1500.01–5000, 5000.01–10 000, >10 000).
- **Логистика Ozon** снизилась в 3–4 раза для товаров ≥5 л, но в сумме большинство селлеров в минусе.
- **Налог**: УСН 6% (либо УСН+НДС 5% без вычетов с >20 млн выручки, либо УСН+НДС 7% с вычетами).

Рабочая формула на 2026:

```
Profit = Price - (COGS + Fulfillment + MP_Commission + Logistics_client + Refunds_logistics
                  + Defect_rate × Price + Ad_spend + Tax_on_revenue)

ROI_year = (Profit_per_batch / Invested_capital) × Cycles_per_year
```

«Зелёная зона» (ориентиры после правок):
- Маржа WB: 15–25% (курс актуален).
- Маржа Ozon: **12–18%** (снизили vs курс 16–22% из-за роста комиссий).
- ДРР WB: 5–10%.
- ДРР Ozon: **15–25%** (увеличиваем резерв).
- Оборот капитала: 2–3 мес (51–104 дня).
- ROI годовой: >150% считать базой, 200–400% — цель.

## 6. Правила запуска без блокировки

Что из курса **ещё работает** в 2026:
- Развозка по 5–6 региональным складам (для WB — критично для топа).
- Кросс-докинг на Ozon ~500 ₽/короб.
- Сбор семантики через топ-20–30 конкурентов по выручке, чистка латиницы/НЧ <1000.
- «Сухое» SEO на Ozon + лишний текст в Rich-контент.
- Аукцион + АвтоРК на WB (при этом исключать ключи из АвтоРК, чтобы не каннибализировать Аукцион).
- На Ozon стартовать с Трафаретов (автостратегия), потом Вывод в топ — только после стабильной конверсии.

Что **не работает** / **опасно** в 2026:
- ❌ Самовыкупы (и на WB, и на Ozon).
- ❌ Болванки «чехол→фен» (запрещено в обеих площадках).
- ❌ Кэшбэк-раздачи с обещанием вознаграждения за отзыв вне «Баллов за отзывы».
- ❌ Дублирование «Баллы за отзывы» (Ozon) + сторонние раздачи — двойная оплата.
- ⚠️ Дробление бизнеса на ИП родственников: запрещены общий IP, склад, сотрудники, внутренние переводы. При обороте >30 млн в «льготном» регионе — обязательное подтверждение присутствия (KZK, Калмыкия, Удмуртия и т.п.) + правило 3 лет.

Что **появилось** и надо учесть:
- ✅ «Баллы за отзывы» — единственный легальный драйвер отзывов на WB. Мин. 21 день, предоплата, старт со след. дня.
- ✅ «Отзывы за баллы» Ozon — встроенный, дешевле сторонних, без риска двойной оплаты.
- ✅ Промокоды продавца на WB (инструмент 2026), собственные акции против массовых общих.
- ✅ Нейросеть отзывов WB (2026) — модерация жёстче, фейковые/копипаст режутся.
- ✅ Сертификат обязателен + ссылка на реестр с сентября 2026 — закладывать в пайплайн.

## 7. Инфографика 2026 — конкретные инсайты

- 2–4 секунды на просмотр карточки: одна идея на один слайд, первый слайд — главное УТП, без текстовой вёрстки преимуществ.
- 3-й слайд **влияет на CTR и открытие** (данные vc.ru: реорганизация карусели → +34% конверсии).
- Текст-преимущества на первых 3 слайдах → ХУЖЕ конверсия, чем упор на визуал.
- Качественная инфографика → CTR +25–40% (данные WB/Ozon).
- На Ozon можно дублировать контент с WB (размеры совместимы), но следить за «индексом цен» — Ozon сравнивает.

## 8. Юридическая гигиена на 2026 (для ИП)

1. **НДС**: при доходе >20 млн ₽/год — либо НДС 5% без вычетов (проще, подходит при малой доле закупа), либо НДС 7% с вычетами (выгоднее при белом импорте и большой доле чужого НДС во входящих).
2. **Льготный регион**: при переезде — правило 3 лет, дорогая подготовка доказательной базы (собственность, местный сотрудник после 30 млн, местные коммуналки/СИМ, членство в Опоре России, пожертвования). Окупается только на оборотах >10–15 млн/год.
3. **Сертификация**: закладывать в юнит-экономику 20–100 тыс ₽ на SKU за декларацию/сертификат, 2–6 недель времени.
4. **Штрихкоды и маркировка** (Честный знак): обязательно для одежды, обуви, парфюма, фототехники, БАД и т.д. Проверить ДО закупки.
5. **Таможня**: ДТ при ≥200 евро/≥31 кг на посылку; оформление через брокера, 3–10 тыс ₽/ДТ.

## 10. Подбор товара — апдейт Q2 2026 (расхождения с курсом)

Курс прошит на видео ~2024 года. На Q2 2026 ряд критериев изменился — ниже сводка с источниками. Пилотный скан 2026-04-27 пересмотрен в свете этого апдейта (см. `scans/2026-04-27-pilot/`).

### 10.1. Окно «новинки» — 14 дней, не «недавно вообще»

> «Newbie-Boost 3.0 даёт продукту максимальный приоритет в выдаче только в первые **14 дней** с момента создания, после чего карточка переходит в общий режим ранжирования. Первая неделя — фаза настройки, вторая — битва за удержание позиций.»
>
> — A3 Agency, 26.04.2026, [«Вывод новинки на WB: пошаговый план»](https://a3-agency.ru/blog/tpost/1j56zrz5e1-vivod-novinki-na-wb-poshagovii-plan-na-p)

**Что это меняет.** Курсовое «недавно заведённые карточки» / наш проектный порог `days_in_site ≤ 180` — это **не «новинка» в Q2 2026**, это товар в общем ранжировании. Окно подражания свежему конкуренту — 2 недели максимум; после этого его рост зависит от обычных факторов, и копирование без преимуществ даёт догоняющую позицию.

### 10.2. Веса ранжирования сместились — отзывы упали с топа

> «Скорость доставки 30–40%; реклама-мультипликатор 15–30%; конверсия карточки 10–20% (≥1.5%); стабильность продаж 10–25%; CTR главного фото 5–15% (≥3%); рейтинг и отзывы 5–10%.»
>
> — SellerKit/FFMP, 25.02.2026, [«Wildberries Search Algorithm Ranking»](https://ffmp.by/blog/wildberries-search-algorithm-ranking)

> «Если товар идёт до клиента дольше 36 часов — карточка автопессимизируется алгоритмом.»
>
> — A3 Agency, [«Алгоритмы ранжирования WB»](https://a3-agency.ru/blog/tpost/1f9eaehra1-algoritmi-ranzhirovaniya-wb-chto-vliyaet)

**Что это меняет.** Регионально распределённые остатки (Тула / Казань / Краснодар + центр) важнее, чем количество отзывов. Курсовый акцент «быстро тающие остатки» подтверждается, но трактовать его теперь надо как *стабильно высокие продажи + распределённые склады*, а не «остаток 5, продаётся за день».

### 10.3. Конкретный порог «маленькое количество отзывов»

Курс цифры не даёт. В нашем `phases.md` / api-catalog был зашит `≤100` — это слишком мягко для Q2 2026, особенно в связке с Newbie-Boost 14 дн.

**Рабочие пороги:**
- **Жёсткий 2026:** `comments ≤ 20` — товар на стадии Newbie-Boost, ещё не успел набрать.
- **Мягкий 2026:** `comments ≤ 30` — товар на грани окна, но всё ещё свежий.
- `≤100` (наше старое значение) — для ретро-просмотра, не для активного скана.

Решение по проекту: использовать **≤30** как дефолт, **≤20** при сужении к Newbie-Boost-кандидатам.

### 10.4. Микрониши вместо «массовых категорий с ростом»

> «Избегать ниш, где 80% выручки забирают 2–3 продавца. Рейтинг конкурентов 3.8–4.2 — потенциально уязвим. Упущенная выручка >30% — индикатор спроса.»
>
> — A3 Agency, 01.04.2026, [«Анализ ниши и конкурентов»](https://a3-agency.ru/blog/tpost/1ysg8xnad1-analiz-nishi-i-konkurentov-poisk-pribiln)

**Что это меняет.** Курсовый список («дом и сад / автотовары / спорт / строительство») в Q2 2026 — это **уровень корня дерева**, дальше внутри них надо искать **subject-уровень с low-supply**. Наш пилот заходил на промежуточный уровень категорий (например, `Сверление, долбление, закручивание`); в следующем цикле имеет смысл сразу спускаться на конкретный subject (Гайковёрты, Перфораторы) и там проверять долю топ-3.

### 10.6. Что курса подтверждается / не подтверждается

| Курсовой критерий | Q2 2026 |
|---|---|
| Категории «дом/сад/авто/спорт» как источник кандидатов | **Расхождение** — корень ОК, но искать на subject-уровне с low-supply |
| Фильтр выручки 100–300К ₽/мес | Свежих 2026-источников с конкретным диапазоном **не нашлось**; продолжаем как Вариант А (буквально) |

### 10.8. Шкала топ-3 трёхзонная (расширение 10.4)

> «Если 80% выручки в категории забирают 2–3 бренда — это не стартовая ниша.»
>
> — A3 Agency, 09.04.2026

Расширяем бинарный фильтр §10.4 до трёх зон по доле топ-3 от оборота subject:

| Зона | Доля топ-3 | Решение |
|---|---:|---|
| **Зелёная** | < 60–65% | Полный go |
| **Жёлтая** | 65–80% | Только с явным неценовым УТП и подтверждённой missed revenue |
| **Красная** | > 80% | Не входить |

**Что это меняет.** Старое «избегать >80%» оставляло слепое пятно 60–80%. Жёлтая зона — это subject, где войти можно, но только при условии fitment-преимущества или экспертного УТП; на чистом ценовом аргументе там не выжить.

### 10.9. Бюджетная привязка выручки конкурента

> «Слой продавцов с оборотом 1–3 млн ₽/мес вытесняет новичков; нацеливаться на subject, где референсные карточки конкурентов стоят в зоне 0.8–2.0 млн ₽ выручки в месяц, а не 3+ млн ₽ на карточку.»
>
> — Точка Банк, 31.03.2026 + A3 Agency, 09.04.2026 (методический вывод)

Курсовой Вариант А (фильтр 100–300К ₽/мес) рассчитан на бюджет закупки 150К ₽. Под бюджет 700K–1M ₽ это слишком тонкая полка: туда попадают мелкие SKU без ёмкости под закупку 600+ единиц.

**Параметризация:** целевая выручка референсной карточки конкурента ≈ **×1.1–×2.9 от проектного бюджета закупки**.

| Бюджет на закупку | Выручка карточки-эталона |
|---:|---:|
| 150 000 ₽ (курс) | 100 000 – 300 000 ₽ (×0.7–×2.0) |
| 700 000 ₽ | 800 000 – 2 000 000 ₽ (×1.1–×2.9) |
| 1 000 000 ₽ | 1 100 000 – 2 900 000 ₽ |

Карточки 3+ млн ₽/мес для бюджета ≤ 1 млн ₽ — **плохой эталон**: за ними стоят селлеры с тяжёлой рекламой и обороткой, новичок там в догоняющей позиции.

**Решение по проекту:** в `methodology-checklist.md` критерий 2 параметризовать формулой `min = 1.1 × budget, max = 2.9 × budget`; курсовое 100–300К оставить как Вариант А только для бюджета 150К.

### 10.10. Дисконтирование выручки склеек

На WB склейка остаётся механикой, а на Ozon с 22.04.2026 договором закреплено: «объединяйте только товары одной модели». Это делает gross-выручку склеенной WB-карточки систематически завышенной для одного SKU-варианта.

| Площадка | Тип склейки | Доля выручки на ваш SKU |
|---|---|---:|
| WB | 5+ активных вариантов | 35–50% |
| WB | 2–4 варианта одной модели | 60–75% |
| Ozon | одна модель (после 22.04.2026) | 70–85% |
| Ozon | набор/серия в одной карточке | оценивать по фактической доле SKU |

Применять дисконт **до** прохождения гейтов §10.9 и шкалы топ-3 — иначе inflated GMV проходит фильтр потенциала, а реальная ёмкость вашего варианта ниже.

В пилотном скане `color_count` MPStats не отдаёт; косвенный сигнал — `start_price/final_price > 5×` (подозрение на болванку), финальный вердикт по числу вариантов берётся из WB UI или Wildbox.Hunter («Анализ склеек» — аналитика совместных заказов и переливов трафика внутри карточки).

Источник: Ozon Seller / договор для продавцов (22.04.2026); WB Partners / документация по объединениям (2026); Wildbox.Hunter, публичная страница инструмента.

### 10.11. Шкала sales/day

| Зона | Sales/day | Что значит |
|---|---:|---|
| **Зелёная** | 3–10 | Рабочий диапазон под бюджет 700K–1M ₽ |
| **Жёлтая** | 1–3 | Допустимо в Newbie-Boost окне (карточка ещё разгоняется) |
| **Жёлтая** | 10–20 | Ёмко, но требует более тяжёлой оборотки и плотной логистики |
| **Красная** | < 1 | Слишком тонко, не окупит ввод нового SKU |
| **Красная** | > 20 | Вне диапазона бюджета — туда идут селлеры с оборотом ≥ 5 млн ₽/мес |

Курсовой проектный порог `sales/day ≥ 0.5` остаётся как **отбраковочный** (карточка не мёртвая), но для активной гипотезы зелёная зона — не «выше 0.5», а **3–10 в среднем за 30 дней**. С учётом Newbie-Boost (≤14 дн жизни): в первые 7 дней допустима зона 1–3, после 14 дн уже ждём ≥3.

### 10.12. Размер ниши

> «Узкая ниша до 1000 товаров — хорошая стартовая зона.»
>
> — МойСклад, Валерия Королева, 18.03.2026

Subject, где в WB-каталоге > 1000 активных SKU, считается уже массовым. Для бюджета 700K–1M ₽ выбираем subject `100–1000` SKU: достаточно конкурентов для статистики, но не так много, чтобы новичка сразу залило ценой.

В пилотном скане `Сверление, долбление, закручивание` и `Триммер садовый` — это всё ещё корневой уровень, не subject. На следующем цикле спускаться сразу до уровня `Гайковёрты ударные / Триммеры аккумуляторные / Перфораторы ≤ 1 кг`.

## 11. Discovery-окна 7/30/90/365 + 36 мес внешний тренд

> «Максимум за последние 365 дней… максимальный интервал — 7 дней.»
>
> — Wildberries API, «Поисковые запросы по вашим товарам», 17.03.2026

> «Игнорирование сезонности — типовая ошибка; проверяйте график спроса за последние 3 года.»
>
> — A3 Agency, 09.04.2026

Стратегический анализ subject в 2026 строится на **четырёх внутрисайтовых окнах WB** + **одном внешнем**.

| Окно | Что смотрим | Источник |
|---|---|---|
| 7 дней | Импульс / краткосрочные изменения позиций | WB orders-by-query (макс 7 дн) |
| 30 дней | Живость спроса / выручка карточки | WB Analytics (revenue, lost_profit) |
| 90 дней | Устойчивость остатков и заказов | WB stocks history (рекомендованное окно) |
| 365 дней | Сезонность vs тренд | WB search queries (макс 365 дн) |
| 36 месяцев (внешний) | Год к году + длинный сезонный паттерн | Wordstat, Google Trends |

Для сезонных subject (садовый/дачный инструмент, шины, отопление, аварийное) одного 365-дневного окна WB **недостаточно** — оно даёт только 1 цикл сезонности. 36 мес внешнего тренда (Wordstat) отделяет погодный всплеск от структурного роста.

### 11.1. Тест «растущая ниша vs сезонный пик»

Растущая ниша в 2026 проходит **три условия одновременно**:

1. **YoY-рост в сопоставимом периоде.** Март-2026 vs март-2025 в Wordstat показывает +X% — а не «скачок к январю».
2. **Спрос вне пика не падает в ноль.** Если в межсезонье `показы/мес` < 10% от пика — это сезонный спайк, не evergreen.
3. **Растут не только заказы, но и поисковые сигналы / корзины / видимость.** Если выручка растёт за счёт перетока из других карточек, а не за счёт расширения top-funnel — это не рост ниши.

Сезонный пик выглядит иначе: кратный рост внутри короткого окна, который быстро сдувается. Релиз Ozon по садовому инструменту 28.03.2026 (лопаты x5.5, тачки x3.5, сучкорезы x4) — пример именно сезонного всплеска, не растущего subject.

**Прикладной вывод.** Для гипотез по садовому/бензо/триммерному инструменту обязательно сверяться с 36 мес Wordstat, иначе мартовский всплеск читается как рост ниши.

## 12. Карта корень → subject 2026 (электро/бензо/авто)

Курсовой список «дом и сад / автотовары / спорт / строительство» — это уровень корня. Для нашей экспертной ниши дип-ресёрч 2026-04-28 даёт следующие subject-уровни.

### 12.1. Электроинструмент

| Зона | Subject | Сигнал 2026 |

### 12.2. Бензоинструмент

> **По теме exact subject-аналитики бензоинструмента публичных материалов 2026 года не найдено.**
>
> — дип-ресёрч 2026-04-28, ограничения

Прямых данных по split «бензо vs аккумуляторный» в 2026 нет. Adjacent-сигналы (триммеры/газонокосилки) показывают живой сезон. Рабочая методика — **не брать broad class «бензоинструмент»**, а резать на сценарии:

- Уход за участком (бензотриммер + расходники)
- Расчистка / подготовка к сезону (бензопила + цепи + масло)
- Расходники и комплектующие (свечи, цепи, шины, пильные диски, защитные комплекты)

**Решение по проекту.** Запуск SKU из этого блока **только после** 12-мес проверки внутри WB/Ozon **и** 36-мес внешнего тренда Wordstat. На пилоте 2026-04-27 ветка `Бензопила (узкая)` гейт A прошла, но subject-аналитика 2026 не подтверждена — приоритет ниже электро.

### 12.3. Автоинструмент и наборы

Прямых 2026-публикаций по subject «наборы автоинструмента» нет, но два косвенных сигнала сильны:

1. **Ozon platform-fit.** «Мужчины чаще покупают автотовары и электронику» (Точка Банк, 13.04.2026). У Ozon «зрелая аудитория, средний доход и выше».
2. **Защита от копирования.** «Новичку проще выйти в нишах, где важна экспертность — запчасти, инструменты, профоборудование» (Netology, апрель 2026).

| Зона | Subject | Защита от 1688-клона |
|---|---|---|
| **Высокий** | Roadside/emergency kits, наборы для колёсного сервиса, мото/велоинструмент | fitment + сценарий |
| **Высокий** | Автоэлектрика, диагностика, съёмники/спецключи под марку авто | глубокая экспертность, узкий сценарий |
| **Средний** | Наборы под конкретный fitment (ВАЗ-классика, Toyota 2.0, BMW E-серия) | хороший контент защищает, но нужна локализация |
| **Не идти** | Универсальные 94/108-предметные наборы | классическая 1688-заготовка, ценовая яма |

## 13. Анти-1688 чек и защищённые подниши

С апреля 2026 на WB зарегистрированы китайские фабрики напрямую (см. §10.5), а маркетплейсы усилили антифрод по «совпадениям изображений и текстов» (Forbes, 07.04.2026). Это меняет risk-profile при выборе SKU: чем легче карточка копируется, тем быстрее придёт фабрика-оригинал.

### 13.1. Четыре признака 1688-копии в карточке-эталоне

Если у конкурента-эталона выполняется ≥3 из 4 — карточка повторяема за вечер, в shortlist не брать (или брать только с обязательной уникализацией):

1. **Фабричные / экспортные фото и инфографика.** Легко гуглятся обратным поиском, выглядят как универсальный экспортный контент, нет российского сценария применения.
2. **Текст без fitment-логики.** Описание собрано из общих фраз, нет привязки к конкретной задаче / совместимости / русскому use case.
3. **Аномально низкая цена.** Цена сразу кажется дешевле адекватного диапазона subject — типовой признак прямого ввоза с 1688 без посредников.
4. **Слабый бренд-контур.** No-name или «псевдороссийский» бренд (латинское название без идентичности, нет упаковки/локализации/инструкции на русском).

### 13.2. Защищённые подниши

«Самые менее уязвимые микрониши для китайских фабрик в 2026 — это не премиум и не модное, а экспертное и fitment-зависимое.»

| Тип подниши | Почему защищено | Примеры |
|---|---|---|
| Fitment-зависимые наборы | Покупателю нужен подбор по марке/модели, фабрика не сделает каталог сразу под весь авторынок РФ | Съёмники под конкретный двигатель, наборы для марки авто, оснастка к российским дрелям |
| Диагностика и сервис | Требует объяснения применения и поддержки | Автодиагностика OBD-2, измерительный инструмент с локализацией |
| Расходники / комплекты | Низкая ценовая лобовая, но многократные покупки | Цепи для бензопил, насадки, ремни, фильтры |
| Экспертный сервис + контент | Защита через консультацию и подбор | МойСклад: «выигрывать сервисом, ремонтом, консультациями, подбором, возможностью покупки комплекта» |

### 13.3. Уникализация (если SKU всё-таки повторяемый)

Для SKU, который **технически 1688-копия** (типовой шуруповёрт, типовой триммер) — обязательная программа защиты:

- Комплект (добавить расходник / насадку / кейс)
- Своя упаковка с локализацией
- Расширенная гарантия (12+ мес против фабричных 6)
- Инструкция на русском с фотографиями
- Свой бренд-контур (упаковка + инфографика + видео)

Без этого карточка проигрывает фабрике по цене сразу, как только фабрика выйдет на WB напрямую.
