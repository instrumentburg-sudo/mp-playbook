## 3. API и лимиты

### Wildberries
- Общий лимит запросов: **3 запроса / 30 секунд** на метод на хост.
- Раздел «Аналитика»: **1 запрос/мин**, 30 строк (100 на тарифах Advanced и Premium Jam), до 100 000 строк в одном ответе.
- Остатки на складах (с 23.03.2026): **1 запрос / 20 секунд**, 250 000 строк.
- Разделы: `/content`, `/statistics`, `/analytics`, `/promotion` (рекламные кампании), `/reports` (финансовые отчёты).
- Документация: `dev.wildberries.ru`, `openapi.wildberries.ru`.

### Ozon Seller API
- С 24.02.2026 единый лимит: **30 000 операций с товарами в минуту**. Превышение — ответ `429` с заголовками `Retry-After` и `Remaining`.
- С 06.04.2026: новый блок `Tarification_steps` в `/v3/posting/fbs/list`; в Performance API для продавцов из РФ внедрили авторизацию OAuth (раньше была только в Seller API).
- С 07.04.2026 устаревшие методы отгрузки со своего склада (FBS / rFBS) объявлены устаревающими.
- Документация: `docs.ozon.ru/api/seller/`, `dev.ozon.ru/news/`.

### 1688 / Alibaba
- Публичного стабильного API для 1688 нет; используется поиск по фото + фильтры в интерфейсе либо посредник или автоматизация через браузер.
- Для Alibaba — официальный сторонний шлюз RapidAPI, но ассортимент и цены хуже, чем на 1688.

## 4. Импорт из Китая — актуальная модель

**Выбор поставщика на 1688** (из курса с современными правками):
1. Поиск по фото, сортировка по обороту (выручке).
2. Иконки на странице фабрики: «красный бык» / «фиолетовый бриллиант» — проверено.
3. Возраст фабрики ≥ 3 лет, доля повторных покупок ≥ 20–35%.
4. Запросить реальные фото и видео (без иероглифов на упаковке — только английский или русский текст).
5. Тестовая мини-партия до основного заказа.
6. На коробках — штрихкоды и маркировка под ЕАЭС (Евразийский экономический союз).

**Логистика**:
- Карго автомобилем: 18–25 дней (экономично, но риск при усилении системы СПОТ).
- Карго быстрым автомобилем: 12–16 дней.
- Авиа: 8–12 дней (дорого).

**Белый и серый импорт** (2026):
- Серый (карго без таможенной декларации) — блокировка сертификатов, штрафы, нельзя в корпоративные продажи, в тендеры и в ЕАЭС.
- Белый — таможенная декларация, сертификат или декларация соответствия с реальными испытаниями, вычет НДС (если на НДС), участие в тендерах, легальный экспорт.
- Для ИП с оборотом > 20 млн ₽ белый путь становится единственным разумным.

## 5. Юнит-экономика — правки 2026

Курс даёт примеры с **комиссией WB 20%** и **Ozon 12%**. На апрель 2026 это нижняя граница; нужно пересчитывать по актуальной таблице комиссий с учётом:

- **Комиссия WB при отгрузке со склада площадки (FBO)** по категориям: 10–25% (стабильна, но логистика при отгрузке со своего склада выросла).
- **Комиссия Ozon при отгрузке со склада площадки (FBO)** с 06.04.2026: 15–55%. Влияет ценовой сегмент: до 100 ₽, 100,01–300, 300,01–1500, 1500,01–5000, 5000,01–10 000, > 10 000.
- **Логистика Ozon** снизилась в 3–4 раза для товаров от 5 литров, но в сумме большинство продавцов в минусе.
- **Автоподписка Ozon «Управление отзывами»** с 01.04.2026 — 0,8–1,3% от оборота, подключается без уведомления продавца. Если не нужна — выключать вручную в кабинете, иначе незаметно съедает долю выручки.
- **Региональные надбавки Ozon** с 01.05.2026 — 6–12% за нелокальные продажи в 4 кластерах (Пермь, Оренбург, Самара, Омск). Если отгружаемся только из центра — закладывать в логистику до клиента.
- **Задержка выплат WB до 3 недель** после публикации еженедельного отчёта (введено в марте 2026, оценка прибавки к WB — 111 млрд ₽ дополнительной прибыли). Удлиняет цикл оборачиваемости капитала на 1–2 недели против курсового расчёта.
- **Налог:** УСН 6% либо УСН + НДС 5% без вычетов с выручки от 20 млн, либо УСН + НДС 7% с вычетами.

Рабочая формула на 2026:

```
Profit = Price - (COGS + Fulfillment + MP_Commission + Logistics_client + Refunds_logistics
                  + Defect_rate × Price + Ad_spend + Tax_on_revenue)

ROI_year = (Profit_per_batch / Invested_capital) × Cycles_per_year
```

«Зелёная зона» (ориентиры после правок):
- Маржа WB: 15–25% (курс актуален).
- Маржа Ozon: **12–18%** (снижена с курсовых 16–22% из-за роста комиссий).
- **Маржа до и после СПП.** Тимур Товарка фиксирует: для Ozon **5% маржи до СПП — рабочая нижняя граница**, после возврата СПП итоговая маржа выходит +15–20%. Не отбрасывать кандидата только по «холодной» марже 5% — сначала проверить, действует ли СПП в категории и какая у неё доля. Считаем два числа: план (до СПП) и факт (после СПП).
- ДРР (доля рекламных расходов) WB: 5–10%.
- ДРР Ozon: **15–25%** (увеличиваем резерв).
- Оборот капитала: 2,5–3,5 месяца (**70–104 дня**, нижняя граница поднята с 51 из-за задержки выплат WB до 3 недель).
- Годовая доходность капитала (ROI): больше 150% — базово, 200–400% — цель.

## 6. Правила запуска без блокировки

Что из курса **ещё работает** в 2026:
- Развозка по 5–6 региональным складам (для WB — критично для попадания в топ).
- Прямая отгрузка через хаб на Ozon — около 500 ₽ за коробку.
- Сбор поисковых запросов через топ-20–30 конкурентов по выручке, чистка латиницы и низкочастотных запросов до 1000 показов.
- «Сухое» описание на Ozon + лишний текст в расширенное описание (Rich-контент).
- «Аукцион» + «АвтоРК» на WB (при этом из «АвтоРК» нужно исключить ключи, чтобы не отнимать заходы у «Аукциона»).
- На Ozon стартовать с «Трафаретов» (автоматическая стратегия), потом «Вывод в топ» — только после стабильной конверсии.

Что **не работает** или **опасно** в 2026:
- Самовыкупы (и на WB, и на Ozon).
- Подмены «чехол → фен» под «заменитель» — запрещены на обеих площадках.
- Раздачи с обещанием вознаграждения за отзыв вне «Баллов за отзывы».
- Совмещение «Баллов за отзывы» Ozon и сторонних раздач — двойная оплата.
- Дробление бизнеса на ИП родственников: запрещены общий интернет-адрес, общий склад, общие сотрудники, переводы между ИП. При обороте > 30 млн в «льготном» регионе — обязательное подтверждение присутствия (Калмыкия, Удмуртия и подобные) + правило 3 лет.

Что **появилось** и нужно учесть:
- «Баллы за отзывы» — единственный легальный способ собирать отзывы на WB. Минимум 21 день, предоплата, старт со следующего дня.
- «Отзывы за баллы» Ozon — встроенный, дешевле сторонних, без риска двойной оплаты.
- Промокоды продавца на WB (инструмент 2026), собственные акции против массовых общих.
- Нейросеть отзывов WB (2026) — модерация жёстче, фейковые и копипаст-отзывы режутся.
- Сертификат обязателен + ссылка на реестр с сентября 2026 — закладывать в конвейер.

## 7. Инфографика 2026 — конкретные наблюдения

- 2–4 секунды на просмотр карточки: одна идея на один слайд, первый слайд — главное преимущество, без текстовой вёрстки преимуществ.
- 3-й слайд **влияет на кликабельность и открытие** (данные vc.ru: реорганизация карусели → +34% к конверсии).
- Текстовые преимущества на первых 3 слайдах — конверсия хуже, чем при упоре на визуал.
- Качественная инфографика — кликабельность +25–40% (данные WB и Ozon).
- На Ozon можно дублировать содержимое с WB (размеры совместимы), но нужно следить за «индексом цен» — Ozon сравнивает цены между площадками.

## 8. Юридическая гигиена на 2026 (для ИП)

1. **НДС:** при выручке свыше 20 млн ₽/год — либо НДС 5% без вычетов (проще, подходит при малой доле закупки), либо НДС 7% с вычетами (выгоднее при белом импорте и большой доле чужого НДС во входящих).
2. **Льготный регион:** при переезде — правило 3 лет, дорогая подготовка доказательной базы (собственность, местный сотрудник после 30 млн, местные коммунальные платежи и сим-карта, членство в «Опоре России», пожертвования). Окупается только на оборотах > 10–15 млн/год.
3. **Сертификация:** закладывать в юнит-экономику 20–100 тыс. ₽ на артикул за декларацию или сертификат, 2–6 недель времени.
4. **Штрихкоды и маркировка** («Честный знак»): обязательно для одежды, обуви, парфюма, фототехники, биодобавок и т. д. Проверять до закупки.
5. **Таможня:** таможенная декларация при сумме посылки от 200 евро или весе от 31 кг; оформление через брокера, 3–10 тыс. ₽ за декларацию.

## 10. Подбор товара — обновление за II квартал 2026 (расхождения с курсом)

Курс снят с видео примерно 2024 года. На II квартал 2026 ряд критериев изменился — ниже сводка с источниками. Пилотный скан 2026-04-27 пересмотрен в свете этого обновления (см. `scans/2026-04-27-pilot/`).

### 10.1. Окно «новинки» — 14 дней, а не «недавно вообще»

> «Newbie-Boost 3.0 даёт продукту максимальный приоритет в выдаче только в первые **14 дней** с момента создания, после чего карточка переходит в общий режим ранжирования. Первая неделя — фаза настройки, вторая — битва за удержание позиций.»
>
> — A3 Agency, 26.04.2026, [«Вывод новинки на WB: пошаговый план»](https://a3-agency.ru/blog/tpost/1j56zrz5e1-vivod-novinki-na-wb-poshagovii-plan-na-p)

**Что это меняет.** Курсовое «недавно созданные карточки» и наш проектный порог «возраст карточки до 180 дней» — это **не «новинка» в II квартале 2026**, это товар в общем ранжировании. Окно подражания свежему конкуренту — 2 недели максимум; после этого его рост зависит от обычных факторов, и копирование без преимуществ даёт догоняющую позицию.

### 10.2. Веса ранжирования сместились — отзывы упали с верха списка

> «Скорость доставки 30–40%; реклама-усилитель 15–30%; конверсия карточки 10–20% (≥ 1,5%); стабильность продаж 10–25%; кликабельность главного фото 5–15% (≥ 3%); рейтинг и отзывы 5–10%.»
>
> — SellerKit / FFMP, 25.02.2026, [«Wildberries Search Algorithm Ranking»](https://ffmp.by/blog/wildberries-search-algorithm-ranking)

> «Если товар идёт до клиента дольше 36 часов — карточка автоматически понижается алгоритмом.»
>
> — A3 Agency, [«Алгоритмы ранжирования WB»](https://a3-agency.ru/blog/tpost/1f9eaehra1-algoritmi-ranzhirovaniya-wb-chto-vliyaet)

**Что это меняет.** Регионально распределённые остатки (Тула / Казань / Краснодар + центр) важнее, чем количество отзывов. Курсовый акцент «быстро тающие остатки» подтверждается, но трактовать его теперь надо как *стабильно высокие продажи + распределённые склады*, а не «остаток 5, продаётся за день».

### 10.3. Конкретный порог «маленькое количество отзывов»

Курс цифры не даёт. В нашем `phases.md` и каталоге MPStats был зашит «не больше 100» — это слишком мягко для II квартала 2026, особенно в связке с окном 14 дней.

**Рабочие пороги:**
- **Жёсткий 2026:** не больше 20 отзывов — товар на стадии бонуса для новичков, ещё не успел набрать.
- **Мягкий 2026:** не больше 30 отзывов — товар на грани окна, но всё ещё свежий.
- Не больше 100 (наше старое значение) — для ретро-просмотра, не для активного скана.

Решение по проекту: использовать **не больше 30** как значение по умолчанию, **не больше 20** при сужении к кандидатам в окне бонуса для новичков.

### 10.4. Микро-ниши вместо «массовых категорий с ростом»

> «Избегать ниш, где 80% выручки забирают 2–3 продавца. Рейтинг конкурентов 3,8–4,2 — потенциально уязвим. Упущенная выручка > 30% — показатель спроса.»
>
> — A3 Agency, 01.04.2026, [«Анализ ниши и конкурентов»](https://a3-agency.ru/blog/tpost/1ysg8xnad1-analiz-nishi-i-konkurentov-poisk-pribiln)

**Что это меняет.** Курсовый список («дом и сад / автотовары / спорт / строительство») в II квартале 2026 — это **уровень корня дерева**, дальше внутри них надо искать **уровень предмета с малым предложением**. Наш пилот заходил на промежуточный уровень категорий (например, «Сверление, долбление, закручивание»); в следующем цикле имеет смысл сразу спускаться до конкретного предмета (Гайковёрты, Перфораторы) и там проверять долю топ-3.

**Что это меняет.** Чистое копирование хита 1688 — риск. Когда фабрика выйдет на WB сама, перекуп проигрывает по цене. **Новый шаг в фазе «Поставщик»:** проверить, не зарегистрирован ли поставщик уже как продавец на WB (по бренду / ИНН / китайскому идентификатору). При риске — обязательная **уникализация** (комплект, цвет, упаковка, локализация инструкции, расширенная гарантия).

### 10.6. Что из курса подтверждается и что не подтверждается

| Курсовой критерий | II квартал 2026 |
|---|---|
| Категории «дом / сад / авто / спорт» как источник кандидатов | **Расхождение** — корень в порядке, но искать на уровне предмета с малым предложением |
| Фильтр выручки 100–300 тыс. ₽/мес | Свежих 2026-источников с конкретным диапазоном **не нашлось**; продолжаем как Вариант А (буквально) |
| Сортировка по новизне (от новых к старым) | **Подтверждается**, но окно — 14 дней (бонус для новичков), а не 180 |
| Маленькое количество отзывов | **Подтверждается** как сигнал, но цифра — не больше 20–30, а не не больше 100 |
| Чистая карточка без склейки | **Подтверждается** косвенно (ранжирование по ценности заказа режет накрутки) |
| Соотношение топ-1 / топ-20 не больше 10× | В свежих 2026-источниках формулы **нет**; остаётся проектная |
| Потенциал не меньше 2,67 × бюджета | В свежих 2026-источниках множителя **нет**; остаётся проектным |

### 10.8. Шкала топ-3 трёхзонная (расширение 10.4)

> «Если 80% выручки в категории забирают 2–3 бренда — это не стартовая ниша.»
>

Расширяем бинарный фильтр §10.4 до трёх зон по доле топ-3 от оборота предмета:

| Зона | Доля топ-3 | Решение |
|---|---:|---|
| **Зелёная** | < 60–65% | Идём в полную работу |

**Что это меняет.** Старое «избегать > 80%» оставляло слепое пятно 60–80%. Жёлтая зона — это предмет, где войти можно, но только при условии преимущества по подбору к марке или модели либо экспертного преимущества; на чистом ценовом аргументе там не выжить.

### 10.9. Привязка целевой выручки конкурента к бюджету

> «Слой продавцов с оборотом 1–3 млн ₽/мес вытесняет новичков; нацеливаться на предмет, где карточки конкурентов-эталонов стоят в зоне 0,8–2,0 млн ₽ выручки в месяц, а не 3+ млн ₽ на карточку.»
>
> — Точка Банк, 31.03.2026 + A3 Agency, 09.04.2026 (методический вывод)

Курсовой Вариант А (фильтр 100–300 тыс. ₽/мес) рассчитан на бюджет закупки 150 тыс. ₽. Под бюджет 700 тыс. – 1 млн ₽ это слишком тонкая полка: туда попадают мелкие артикулы без ёмкости под закупку 600+ единиц.

**Параметризация:** целевая выручка карточки-эталона ≈ **× 1,1–× 2,9 от проектного бюджета закупки**.

| Бюджет на закупку | Выручка карточки-эталона |
|---:|---:|
| 150 000 ₽ (курс) | 100 000 – 300 000 ₽ (× 0,7 – × 2,0) |
| 700 000 ₽ | 800 000 – 2 000 000 ₽ (× 1,1 – × 2,9) |
| 1 000 000 ₽ | 1 100 000 – 2 900 000 ₽ |

Карточки от 3 млн ₽/мес для бюджета до 1 млн ₽ — **плохой эталон**: за ними стоят продавцы с тяжёлой рекламой и оборотом, новичок там в догоняющей позиции.

**Решение по проекту:** в `methodology-checklist.md` критерий 2 параметризовать формулой `min = 1,1 × бюджет, max = 2,9 × бюджет`; курсовое 100–300 тыс. оставить как Вариант А только для бюджета 150 тыс.

### 10.10. Дисконт выручки склеек

На WB склейка остаётся работающей механикой, а на Ozon с 22.04.2026 договором закреплено: «объединяйте только товары одной модели». Это делает общую выручку склеенной WB-карточки систематически завышенной для одного варианта артикула.

| Площадка | Тип склейки | Доля выручки на ваш артикул |
|---|---|---:|
| WB | 5+ активных вариантов | 35–50% |
| WB | 2–4 варианта одной модели | 60–75% |
| Ozon | одна модель (после 22.04.2026) | 70–85% |
| Ozon | набор/серия в одной карточке | оценивать по фактической доле артикула |

Применять скидку **до** прохождения проверок §10.9 и шкалы топ-3 — иначе завышенная выручка проходит фильтр потенциала, а реальная ёмкость вашего варианта ниже.

В пилотном скане поле количества цветов MPStats не отдаёт; косвенный сигнал — отношение `start_price/final_price` больше 5× (подозрение на товар-«заменитель»), финальный вердикт по числу вариантов — из интерфейса WB или из Wildbox.Hunter («Анализ склеек» — аналитика совместных заказов и переливов заходов внутри карточки).

### 10.11. Шкала продаж в день

| Зона | Продаж в день | Что значит |

| **Зелёная** | 3–10 | Рабочий диапазон под бюджет 700 тыс. – 1 млн ₽ |

## 11. Окна разведки 7 / 30 / 90 / 365 + 36 месяцев внешнего тренда

> «Максимум за последние 365 дней… максимальный интервал — 7 дней.»
>
> — Wildberries API, «Поисковые запросы по вашим товарам», 17.03.2026

> «Игнорирование сезонности — типовая ошибка; проверяйте график спроса за последние 3 года.»
>
> — A3 Agency, 09.04.2026

Стратегический анализ предмета в 2026 строится на **четырёх внутренних окнах WB** + **одном внешнем**.

| Окно | Что смотрим | Источник |
|---|---|---|
| 7 дней | Импульс и краткосрочные изменения позиций | WB, заказы по запросу (максимум 7 дней) |
| 30 дней | Живость спроса, выручка карточки | WB Analytics (выручка, упущенная прибыль) |
| 90 дней | Устойчивость остатков и заказов | WB, история остатков (рекомендованное окно) |
| 365 дней | Сезонность против тренда | WB, поисковые запросы (максимум 365 дней) |
| 36 месяцев (внешнее) | Год к году + длинный сезонный рисунок | Wordstat, Google Trends |

Для сезонных предметов (садовый и дачный инструмент, шины, отопление, аварийное оборудование) одного 365-дневного окна WB **недостаточно** — оно даёт только один цикл сезонности. 36 месяцев внешнего тренда (Wordstat) отделяет погодный всплеск от структурного роста.

### 11.1. Тест «растущая ниша против сезонного пика»

Растущая ниша в 2026 проходит **три условия одновременно**:

1. **Рост год к году в сопоставимом периоде.** Март 2026 против марта 2025 в Wordstat показывает рост на X% — а не «скачок к январю».
2. **Спрос вне пика не падает в ноль.** Если в межсезонье показы в месяц меньше 10% от пика — это сезонный всплеск, не круглогодичный товар.
3. **Растут не только заказы, но и поисковые сигналы, корзины, видимость.** Если выручка растёт за счёт перетока из других карточек, а не за счёт расширения верхней части воронки — это не рост ниши.

Сезонный пик выглядит иначе: кратный рост внутри короткого окна, который быстро сдувается. Релиз Ozon по садовому инструменту 28.03.2026 (лопаты × 5,5, тачки × 3,5, сучкорезы × 4) — пример именно сезонного всплеска, не растущего предмета.

**Прикладной вывод.** Для гипотез по садовому, бензиновому и триммерному инструменту обязательно сверяться с 36 месяцами Wordstat, иначе мартовский всплеск читается как рост ниши.

## 13. Защита от копирования с 1688 и защищённые подниши

С апреля 2026 на WB зарегистрированы китайские фабрики напрямую (см. §10.5), а площадки усилили защиту от мошенничества по «совпадениям изображений и текстов» (Forbes, 07.04.2026). Это меняет профиль риска при выборе артикула: чем легче карточка копируется, тем быстрее придёт фабрика-оригинал.

### 13.1. Четыре признака копии с 1688 в карточке-эталоне

Если у конкурента-эталона выполняется не меньше 3 из 4 — карточка повторяема за вечер, в короткий список не брать (или брать только с обязательной уникализацией):

1. **Фабричные / экспортные фото и инфографика.** Легко гуглятся обратным поиском, выглядят как универсальный экспортный контент, нет российского сценария применения.
2. **Текст без логики подбора по марке.** Описание собрано из общих фраз, нет привязки к конкретной задаче, совместимости или русскому сценарию использования.
3. **Аномально низкая цена.** Цена сразу кажется дешевле адекватного диапазона предмета — типовой признак прямого ввоза с 1688 без посредников.
4. **Слабый бренд.** Безымянный или «псевдороссийский» бренд (латинское название без идентичности, нет упаковки, локализации, инструкции на русском).

### 13.2. Защищённые подниши

«Самые менее уязвимые микро-ниши для китайских фабрик в 2026 — это не премиум и не модное, а экспертное и зависящее от подбора по марке или модели.»

| Тип подниши | Почему защищено | Примеры |
|---|---|---|
| Наборы с подбором по марке | Покупателю нужен подбор по марке или модели, фабрика не сделает каталог сразу под весь авторынок РФ | Съёмники под конкретный двигатель, наборы для марки авто, оснастка к российским дрелям |
| Диагностика и сервис | Требует объяснения применения и поддержки | Автодиагностика OBD-2, измерительный инструмент с локализацией |
| Расходники и комплекты | Низкая ценовая «лобовая», но многократные покупки | Цепи для бензопил, насадки, ремни, фильтры |
| Экспертный сервис и контент | Защита через консультацию и подбор | МойСклад: «выигрывать сервисом, ремонтом, консультациями, подбором, возможностью покупки комплекта» |

### 13.3. Уникализация (если артикул всё-таки повторяемый)

Для артикула, который **технически копия с 1688** (типовой шуруповёрт, типовой триммер) — обязательная программа защиты:

- Комплект (добавить расходник, насадку, кейс).
- Своя упаковка с локализацией.
- Расширенная гарантия (12+ месяцев против фабричных 6).
- Инструкция на русском с фотографиями.
- Свой бренд (упаковка + инфографика + видео).
