## О методичке

База — курс *«Конвейер новинок маркетплейсы»* (11 источников, извлечён через NotebookLM). Обогащена свежими практиками на **23 апреля 2026:** закрытие Moneyplace, рост комиссий Ozon до 55%, порог НДС в 20 млн ₽, ужесточение правил товаров-«заменителей» и отзывов, сертификация со ссылкой в реестр с сентября 2026.

Профиль читателя — опытный продавец с оборотом от 5 млн ₽/мес, который ищет более прибыльные ниши. Фокус смещён с «научить запускать» на «отбор и отбраковку по цифрам до закупки».

## Что здесь

**Курс** — сжатое извлечение в 5 разделах: методология, поиск товара на 1688, юнит-экономика, поисковая оптимизация карточки, запуск и реклама.

**Обновления 2026** — что из курса устарело и какие API реально доступны сегодня. Отдельно — каталог MPStats API под наш конвейер (маппинг «правило → точка доступа»).

**Инструмент** — текстовый план помощника `/mp-new-product`, принятые решения, фазы конвейера с жёсткими контрольными точками, бюджет конвейера и цикл денег.

## Как читать

Последовательно по разделам слева, либо с любого места — каждый раздел самодостаточен. Ключевой документ для согласования перед стартом стартовой версии — «Принятые решения».
