# Бюджет конвейера и цикл денег

Конвейер новинок работает только если в каждый момент времени в фонде есть деньги на следующую закупку. Эта страница — компактная выжимка финансовой модели. Полная визуальная версия с Chart.js, таймлайном и матрицей рисков живёт отдельно: **[instrumentburg-sudo.github.io/wb-china-strategy](https://instrumentburg-sudo.github.io/wb-china-strategy/)**.

## TL;DR

Каждая выплата от WB автоматически раскидывается по шести конвертам. 12% уходят в **Фонд новинок** — именно из него оплачиваются закупки следующих SKU в конвейере. Цикл возврата одной закупки: **95–175 дней** (Китай 60–135 дн + WB-выплата 35–40 дн).

## Формула конвертов

Каждая выплата от WB — любой суммы — раскидывается по одной и той же пропорции. Без раздумий, автоматически.

| Конверт | Доля | Назначение |
|---|---|---|
| Закупка KinQuin | 65% | основной поставщик, постоплата |
| Операционка | 8% | ФОТ (сотрудник 1: 40К + 15% прибыли; сотрудник 2: 25% остатка), фулфилмент ~70К/мес |
| Налоги | 6% | УСН 1% (льготный регион) + НДС 5% |
| **Фонд новинок** | **12%** | **закупка следующих SKU конвейера (Китай 1688 или параллельные ниши)** |
| Резерв | 4% | буфер под задержки WB-выплат (сейчас до 6 нед вместо 35 дн) |
| Владельцу | 5% | регулярный вывод |

После выхода нового магазина (Китай) на самоокупаемость — фонд убирается, каждый магазин живёт на своих деньгах.

## Цикл денег

```
┌────────── 60–135 дней ──────────┬──────── 35–40 дней ──────────┐
│                                  │                                │
│   оплата фабрике → производство  │   товар на WB → продажа →    │
│   → доставка → таможня           │   выплата через 35–40 дн      │
│                                  │                                │
│   (60 дн если оплата по приезду  │   (до 6 недель весной 2026   │
│    через посредника в Екб,       │    из-за новой оферты WB)    │
│    135 дн классика 30/70)        │                                │
└──────────────────────────────────┴────────────────────────────────┘
```

**Итог**: от выложенных денег до поступления на счёт — **95–175 дней**. Это задаёт минимальный размер фонда: он должен покрывать 2–3 средних закупки, иначе цикл рвётся.

## Связь с фазами пайплайна

Бюджет влияет на **три фазы** конвейера новинок:

- **Фаза 2 MARKET**: бюджет задаёт фильтр выручки конкурентов. При бюджете 150К — ищем SKU с выручкой 100–300К/мес. См. [mpstats-api-catalog](../updates/mpstats-api-catalog/) — там этот фильтр уже зашит в пример скрипта.
- **Фаза 4 UNIT-ECO**: ROI-гейт считается от доступного капитала. Оборачиваемость ≤90 дней — это производная от цикла денег.
- **Фаза 5 BUY**: перед подписанием инвойса проверяем — хватает ли в Фонде новинок на текущую закупку + буфер на следующую (3 средних закупки минимум).

## Как быстро оценить бюджет на следующую новинку

Минимальный чек для расчёта:

1. **Средняя выплата WB за 4 недели** (возьми из ТруСтат или из выгрузки WB Finance).
2. **×12% = приток в Фонд новинок за 4 недели.**
3. **×3 = минимальный размер фонда под новинку** (запас на 3 цикла).
4. Если текущий фонд ≥ этого минимума — можно начинать MARKET. Иначе — ждём наполнения.

Пример: выплаты ~2,7М/мес → приток в фонд ~325К/мес → минимальный фонд ~1М. Это примерно соответствует бюджету на один китайский заказ первой партии из wb-china-strategy (700К–1,5М).

## Красные линии

Из [wb-china-strategy/#risks](https://instrumentburg-sudo.github.io/wb-china-strategy/#risks):

- **Никогда** не брать деньги из конверта «Закупка KinQuin» на китайские закупки. Потоки не смешиваются.
- При задержке WB-выплат сначала страдают **Владельцу** и **Резерв**, только потом — закупка.
- Если Резерв падает до нуля — стоп на новые закупки Китая до стабилизации выплат.
