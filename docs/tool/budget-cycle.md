# Бюджет конвейера и цикл денег

Конвейер новинок работает только если в каждый момент времени в фонде есть деньги на следующую закупку. Эта страница — компактная выжимка финансовой модели. Полная визуальная версия с графиками, временной шкалой и матрицей рисков живёт отдельно: **[instrumentburg-sudo.github.io/wb-china-strategy](https://instrumentburg-sudo.github.io/wb-china-strategy/)**.

## Коротко

Каждая выплата от WB автоматически раскидывается по шести конвертам. 12% уходят в **Фонд новинок** — именно из него оплачиваются закупки следующих артикулов в конвейере. Цикл возврата одной закупки: **95–175 дней** (Китай 60–135 дней + выплата от WB 35–40 дней).

## Формула конвертов

Каждая выплата от WB — любой суммы — раскидывается по одной и той же пропорции. Без раздумий, автоматически.

| Конверт | Доля | Назначение |
|---|---|---|
| Закупка KinQuin | 65% | Основной поставщик, оплата после поставки |
| Операционка | 8% | Зарплаты (сотрудник 1: 40 тыс. + 15% прибыли; сотрудник 2: 25% остатка), подготовка к отгрузке ~70 тыс./мес |
| Налоги | 6% | УСН 1% (льготный регион) + НДС 5% |
| **Фонд новинок** | **12%** | **закупка следующих артикулов конвейера (Китай 1688 или параллельные ниши)** |
| Резерв | 4% | Буфер под задержки выплат WB (сейчас до 6 недель вместо 35 дней) |
| Владельцу | 5% | Регулярный вывод |

После выхода нового магазина (Китай) на самоокупаемость — фонд убирается, каждый магазин живёт на своих деньгах.

## Цикл денег

```
┌────────── 60–135 дней ──────────┬──────── 35–40 дней ──────────┐
│                                  │                                │
│   оплата фабрике → производство  │   товар на WB → продажа →    │
│   → доставка → таможня           │   выплата через 35–40 дней    │
│                                  │                                │
│   (60 дн если оплата по приезду  │   (до 6 недель весной 2026   │
│    через посредника в Екб,       │    из-за новой оферты WB)    │
│    135 дн классика 30/70)        │                                │
└──────────────────────────────────┴────────────────────────────────┘
```

**Итог:** от выложенных денег до поступления на счёт — **95–175 дней**. Это задаёт минимальный размер фонда: он должен покрывать 2–3 средних закупки, иначе цикл рвётся.

## Связь с фазами конвейера

Бюджет влияет на **три фазы** конвейера новинок:

- **Фаза 2 РЫНОК:** бюджет задаёт фильтр выручки конкурентов. При бюджете 150 тыс. — ищем артикулы с выручкой 100–300 тыс./мес. См. [mpstats-api-catalog](../updates/mpstats-api-catalog/) — там этот фильтр уже зашит в пример скрипта.
- **Фаза 4 ЮНИТ-ЭКОНОМИКА:** контрольная точка по доходности считается от доступного капитала. Оборачиваемость не больше 90 дней — это производная от цикла денег.
- **Фаза 5 ЗАКУПКА:** перед подписанием счёта проверяем — хватает ли в Фонде новинок на текущую закупку + буфер на следующую (минимум 3 средних закупки).

## Как быстро оценить бюджет на следующую новинку

Минимальный чек для расчёта:

1. **Средняя выплата WB за 4 недели** (взять из Трустата или из выгрузки WB Finance).
2. **× 12% = приток в Фонд новинок за 4 недели.**
3. **× 3 = минимальный размер фонда под новинку** (запас на 3 цикла).
4. Если текущий фонд не меньше этого минимума — можно начинать «Рынок». Иначе — ждём наполнения.

Пример: выплаты ~2,7 млн/мес → приток в фонд ~325 тыс./мес → минимальный фонд ~1 млн. Это примерно соответствует бюджету на один китайский заказ первой партии из wb-china-strategy (700 тыс. – 1,5 млн).

## Красные линии

Из [wb-china-strategy/#risks](https://instrumentburg-sudo.github.io/wb-china-strategy/#risks):

- **Никогда** не брать деньги из конверта «Закупка KinQuin» на китайские закупки. Потоки не смешиваются.
- При задержке выплат WB сначала страдают «Владельцу» и «Резерв», только потом — закупка.
- Если «Резерв» падает до нуля — стоп на новые закупки Китая до стабилизации выплат.
