# Скан садовой АКБ-техники 2026-05-02

Второй прогон фазы 1 ИДЕЯ — первый по обновлённой тактике с шагом 5b «Факт-проверка через Insight» ([`runbook-discovery-1h.md`](../updates/runbook-discovery-1h/)). Цель — найти кандидатов в трёх садовых subject под бюджет 1 млн ₽ в активный сезон 2026.

## Коротко

3 subject отсканированы → один прошёл по полной разведке (культиваторы аккумуляторные, 5 живых кандидатов с упущенной выручкой ≥ выручки) → визуальная проверка вскрыла **4 из 4 признаков копии с 1688 у всех 5**. Без уникализации §13.3 ниша заходима только как ценовая война, что под бюджет 1 млн нерационально.

## 6. Защита от копии с 1688 (§13.1) — критический фактор

Визуальная проверка инфографики 5 карточек:

| Признак §13.1 | 681 | 680 | 056 | 213 | 923 |
|---|:-:|:-:|:-:|:-:|:-:|
| Фабричные / экспортные фото и инфографика (рендер инструмента + рука в перчатке + универсальный фон) | ✓ | ✓ | ✓ | ✓ | ✓ |
| Текст без логики подбора по марке (универсальный «культиватор для дачи») | ✓ | ✓ | ✓ | ✓ | ✓ |
| Аномально низкая цена для класса (5–9 К ₽ при норме 10–15 К) | ✓ | ✓ | ✓ | ✓ | ✓ |
| Слабый бренд (безымянный или псевдоевропейский) | ✓ | ✓ | ✓ | ✓ | ✓ |
| **Признаков из 4** | **4** | **4** | **4** | **4** | **4** |

Конкретно:
- **Горный Расцвет** — карточки без бренда, с инфографикой «Без бензина и проводов» + «2 АКБ в комплекте». Фабричные рендеры на унифицированном синем фоне.
- **Mikleider** — псевдо-немецкий бренд (флаг ФРГ + «Немецкие технологии» / «Немецкое качество»). Фабричный рендер + рука в перчатке.
- **VZV / EXCAVATOR** — самый агрессивный псевдо-европейский маркетинг («Premium качество», «Немецкое качество», флаг ФРГ, 21V Li-Ion в красной плашке).

Правило §13.1: при ≥3 из 4 признаков — карточка повторяема за вечер, **в финал не пускать без обязательной уникализации §13.3**. У всех 5 — 4/4. Заходить как пятый клон бесперспективно: апрель 2026 открыл прямую регистрацию селлеров КНР на WB ([§10.5](../updates/best-practices/)) — фабрика, делающая эти культиваторы, может выйти на WB сама и снести нас по цене.

## 7. Что делать с шорт-листом

Из 5 кандидатов **ни один не идёт прямой копией** в фазу ПОСТАВЩИК. Возможные варианты захода:

1. **Уникализация §13.3** — свой бренд + локальная гарантия (РФ-сервис) + русская инструкция + российский сертификат. Ставка на доверие, не на цену. Цена выше клонов на 15–25 %, но узнаваемость и снятие страха «китайская одноразовая» закрывают эту маржу.
2. **Комплект** — культиватор + сменные насадки (плужок, окучник, прополочные диски) + кейс. Дифференциация по комплекту, а не по модели.
3. **Сценарий-ниша** — узкая обработка для теплицы (≤20 см), либо лёгкий вариант под пожилых пользователей. Уход от прямой конкуренции «универсальный культиватор».

## 8. Что осталось ручное (перед SUPPLIER)

1. **Wordstat YoY 36 мес** «культиватор аккумуляторный» / «электрокультиватор» — растущая ниша или сезонный пик апреля? Без этого риск зайти в спадающее окно. Ozon-релиз марта 2026 показывал рост садовой техники ×2 — но это короткий месячный пик, нужна 36-месячная картинка.
2. **Открыть 5 карточек в браузере** — посмотреть всю инфографику (10–14 слайдов), описания, разницу в комплектации между парами одного супплаера, цвета фрез/корпуса.
3. **Поиск на 1688** «cordless cultivator 21V» / «battery rotary cultivator» — найти ту же фабричную модель, узнать FOB-цену и MOQ, проверить **не зарегистрирован ли поставщик уже на WB** (§10.5).

## 9. Воздуходувки и кусторезы — почему не сейчас

- **Воздуходувки**: топ NB-карточки `967605255` живёт 14 дней с выручкой 16 К ₽, остальные 9 NB-карточек — 0–2 дня и `revenue=0`. Сезон только-только начинается, либо ниша зрелая и новинки не пробивают (топ-1 за 153 дня — 2,05 млн/мес, цена 913 ₽, sales/day 76,7). Под бюджет 1 млн полки нет. Вернуться через 2–4 недели, когда у новых карточек накопится 30 дней Insight-данных.
- **Кусторезы / секаторы аккум.**: топ-NB карточка `951950309` — 16 дней, 0 отзывов, выручка 210 К ₽. Это **в 5 раз ниже** полки 1,1 млн. Под бюджет 1 млн ниша мелкая в принципе — концентрация спроса в ручных моделях, не аккумуляторных.

## 10. Что зафиксировано для следующего скана

1. **Insight = факт-источник** — расхождение с категорийной оценкой <2 % в этой нише. Можно опираться на category-revenue для скрининга, item-sales — финальная сверка перед SUPPLIER.
2. **§13.1 — обязательная визуальная проверка** до открытия brief.yaml. Цифры могут показать «зелёный коридор», но если 4/4 признака копии — кандидат идёт только под план уникализации.
3. **Парные карточки одного супплаера** (1 АКБ / 2 АКБ конфигурации) — это **тактика конкурентов**, которую стоит перенять при заходе. Один nm_id занимает одну позицию в выдаче, два — две.
4. **Sales/активный день vs sales/день с продажами** — две разные метрики. При прерывистых остатках разница в 2–3×. В шкале §10.11 использовать sales/активный день (по дням `balance>0`); sales/день с продажами — для оценки пиковой пропускной способности логистики продавца.
